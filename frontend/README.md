# タスク管理アプリ - フロントエンド

Next.js + Tailwind CSS によるタスク管理 UI。IT開発現場向けのカンバン・ポモドーロ・AIチャット機能付き。

## 構成

```
task-manager-frontend/
├── app/
│   └── page.tsx         # メインページ（ビュー切り替え・ポモドーロ管理）
├── components/
│   ├── KanbanBoard.tsx  # カンバンボード
│   ├── FocusView.tsx    # フォーカスビュー
│   ├── CalendarView.tsx # カレンダービュー
│   ├── ChatView.tsx     # AIチャットビュー
│   ├── TaskCard.tsx     # タスクカード
│   ├── TaskForm.tsx     # タスク作成・編集フォーム
│   └── PomodoroTimer.tsx # ポモドーロタイマー（ヘッダーバー）
├── lib/
│   └── api.ts           # APIクライアント
└── public/
```

## セットアップ

```bash
cd /path/to/task-manager-frontend
npm install
```

## 起動

```bash
# バックエンドを先に起動しておく
npm run dev
```

フロントエンドは http://localhost:3000 で起動します。
バックエンドは http://localhost:8000 が必要です。

## 機能一覧

### カンバンボード
- タスクをドラッグ＆ドロップでステータス変更
- 未着手 / 進行中 / 完了 / 回答待ち の4列

### フォーカスビュー
- 優先度・期限でソートされたタスク一覧
- ポモドーロタイマーとの連携

### カレンダービュー
- 期限日ベースでタスクをカレンダー表示

### AIチャット
- 自然言語でタスクを作成・完了・更新
- Groq API (llama-3.1-8b-instant) による日本語処理
- 例：「設計書レビューを来週金曜までに追加」「見積依頼は完了した」

### ポモドーロタイマー
- タスクカードから作業時間（5/15/25/50分）を選択して開始
- ヘッダーに常駐表示（実行中のみ表示）
- 作業 → 休憩の自動切り替え

## タスクのステータス・優先度

**ステータス:** 未着手 / 進行中 / 完了 / 回答待ち
**優先度:** 高 / 中 / 低

## バックエンドとの接続

`lib/api.ts` の `API_BASE` でバックエンドURLを設定しています（デフォルト: `http://localhost:8000`）。
